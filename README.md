# PlugVR support

[PlugVR](https://plugvr.app) is a VR video player for Meta Quest 3 and Quest 3S. It plays your own video library from
the Stash server on your home network.

Found a bug, miss a feature, have a question, or just something to say? Tell us here. Anything helps, in any form.

There is no code in this repository: PlugVR is closed source, and this is where its issues are.

## Open an issue

[Open an issue](https://github.com/plugvr-studio/plugvr/issues/new/choose). You need a GitHub account. Pick whichever
fits, or start from a blank one and write it your own way:

| | For |
|---|---|
| **Bug report** | Something in PlugVR doesn't work as it should |
| **Feature request** | Something PlugVR doesn't do yet, or could do better |
| **Question** | Help with setting up or using PlugVR |
| **Blank issue** | Anything else, or any of these in your own words |

A form asks for one box only; the rest is there to fill in if you can. PlugVR sends us nothing, so we only learn about
a problem when someone tells us, and for a bug these help us find it sooner:

- The app version, your headset (Quest 3 or 3S) and its Horizon OS version.
- Your Stash version, and whether the server is on the same network as the headset.
- What you expected and what happened.
- For a playback problem: the video's resolution, codec and VR format.
- A screenshot or capture from the headset.

In PlugVR, **Settings → General → About** shows the app's version and your server's Stash version.

## Keep your library private

Everything written here is public. Never post your API key; we will never ask for it. Scene titles, performer names,
your server's address and pictures of your library don't belong in an issue: leave them out, or send them by email.
We remove them from an issue when we find them.

## Maybe answered already

- [Troubleshooting](https://plugvr.app/support#troubleshooting): the server can't be reached, the API key is refused,
  a video looks wrong or doesn't play.
- [Questions](https://plugvr.app/support#faq): what PlugVR needs, plays and doesn't do.
- [The setup guide](https://plugvr.app/setup): connecting by QR code or by typing.
- [The issues so far](https://github.com/plugvr-studio/plugvr/issues?q=is%3Aissue): if yours is there, add to it.

## By email

[info@plugvr.app](mailto:info@plugvr.app), for anything you'd rather not write in public, or if you have no GitHub
account. In PlugVR, **Send feedback** under Settings → General → About shows a QR code that starts that email on your
phone, with the versions filled in.

**Security problems** go to the same address, privately, before telling anyone else. Never into an issue.

## The Stash plugins

Pair QR and Reset resume time have a repository of their own, with their own issues:
[plugvr-studio/stash-plugins](https://github.com/plugvr-studio/stash-plugins).

PlugVR is an independent app, not affiliated with Stash or Meta.
